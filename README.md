# Claarify downloads

Official release downloads and update information for Claarify.

## Availability

- **macOS:** Claarify 0.1.0 is the first regular release, for macOS 14 or later on Apple Silicon and Intel Macs. [Download for Mac](https://github.com/josephcaudill293/claarify-releases/releases/latest/download/Claarify-macOS.dmg).
- **Windows:** Planned. No Windows app is available yet.

## Installation

Open Claarify-macOS.dmg. Drag Claarify onto the Applications folder shortcut, open Claarify from Applications, and eject the disk image.

The app is locally signed and not Apple-notarized; macOS may require manual approval in System Settings > Privacy & Security. GitHub's source archives are not app installers.

## Automatic updates

The signed Mac Sparkle feed is published and update checking has been confirmed. Full upgrade/relaunch testing remains to be completed. Windows will use a separate feed when available. The update-feed release contains update information, not an app download.

## Feedback

Report problems through [Issues](https://github.com/josephcaudill293/claarify-releases/issues). Include the app version, operating system, and reproduction steps. Issues are public; omit private logs and personal information.

This repository contains finished apps and public release information. Application source code and private signing keys are not published here.
