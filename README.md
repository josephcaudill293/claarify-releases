# Claarify downloads

Official release downloads and update information for Claarify.

## Availability

- **macOS:** [0.1.0 Beta 1](https://github.com/josephcaudill293/claarify-releases/releases/tag/macos-v0.1.0-beta.1) is available for testing on macOS 14 or later, for Apple Silicon and Intel Macs. Installation and upgrade testing are still in progress.
- **Windows:** Planned. No Windows app is available yet.

## Installation

Download the Claarify-macOS ZIP from the beta release, extract it, and move Claarify to Applications. This beta is locally signed and not Apple-notarized; macOS may require manual approval in System Settings > Privacy & Security. GitHub's automatically generated source archives are not app installers.

## Automatic updates

The signed Mac Sparkle feed is published. Future versions use this feed; a full installation/relaunch update test remains to be completed. Windows will use a separate feed when available. The update-feed release contains update information, not an app download.

## Feedback

Report problems through [Issues](https://github.com/josephcaudill293/claarify-releases/issues). Include the app version, operating system, and steps to reproduce. Issues are public; omit private logs and personal information. Keep workspace backups during beta testing.

This repository contains finished apps and public release information. Application source code and private signing keys are not published here.
