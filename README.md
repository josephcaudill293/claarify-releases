# Claarify downloads

Official release downloads and update information for Claarify.

## Availability

- **macOS:** Beta preparation is underway. No downloadable beta has been published yet.
- **Windows:** Planned. A Windows application and installer are not available yet.

## Downloads

Published app downloads will appear under [Releases](https://github.com/josephcaudill293/claarify-releases/releases). Download only the asset labeled for your operating system. GitHub's automatically generated source archives are not app installers.

## Automatic updates

The release hosting will use separate macOS and Windows update feeds. macOS uses Sparkle; the planned Windows integration uses WinSparkle, subject to the Windows application's implementation. Automatic updates are not live yet.

## Feedback

Report problems through [Issues](https://github.com/josephcaudill293/claarify-releases/issues). Include the app version, operating system, and steps to reproduce. Issues are public; omit private logs and personal information.

This repository distributes finished apps and public release information. Claarify's application source code and private signing keys are not published here.
